# The Agent's Uh-Oh — `recalculating`

One word an agent says when it has no idea what to do: **recalculating** —
the sound a lost machine makes while it quietly figures out where it went wrong.

## Entry

`main.py` (pure Python 3 stdlib, no network) copies the one word from
`entry.txt` to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).

```sh
python3 main.py
```
